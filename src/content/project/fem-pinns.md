This project modeled magnetic fields using the finite element method in NGSolve and simulated charged particle trajectories in Python using a fourth-order Runge–Kutta scheme.

A physics-informed neural network (PINN), implemented in PyTorch, was then evaluated for the Lorentz force equation.

The project received a grade of **6/6**. The report and implementation are linked alongside this description.
